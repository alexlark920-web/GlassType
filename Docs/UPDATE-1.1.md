# Обновление 1.1: отклик, удержание и прозрачность

## Использование

- На клавиатуре нажмите **⚙**. Этот экран доступен даже при выключенных подсказках.
- «Виброотклик»: нет / слабый / средний / сильный. По умолчанию выключен; используются light/medium/heavy `UIImpactFeedbackGenerator`, без звуковых или приватных API.
- «Символы удержанием»: цифры на верхнем ряду, знаки на остальных. Языковые варианты (`ё`, `ґ`, диакритика) сохраняются при выключении опции.
- «Метки на клавишах»: маленький символ справа вверху; выключение скрывает метки, сохраняя само удержание.
- «Удержание»: 0,25 / 0,4 / 0,6 секунды.
- Нажмите «Готово». При удержании первый дополнительный символ уже выбран; отпустите для ввода либо сдвиньте палец по горизонтали к другому варианту. Справа панель раскрывается влево.

Эти параметры также есть в основном приложении. Параметры, изменённые через ⚙, сохраняются в локальном sandbox расширения и имеют приоритет. Так они работают после переподписи SideStore даже без App Group. «Сбросить локальные настройки» убирает приоритет: используются доступные общие настройки или значения по умолчанию. Общие настройки приложения по-прежнему зависят от App Group и Full Access.

Haptic — запрос к iOS, а не гарантия физической вибрации. Устройство, iOS, системные настройки тактильных сигналов и доступ расширения могут подавлять отклик. При отсутствии отклика проверить режим «Сильно», Full Access, системные параметры и физический iPhone; симулятор не заменяет проверку Taptic Engine.

## Фон

Убрана непрозрачная заливка корневого view. Подложка использует адаптивный `UIVisualEffectView` с `systemThinMaterial`, поэтому следует системной теме и размывает доступное содержимое под ней. Никаких снимков экрана приложения-хоста не создаётся. Плашки клавиш остаются непрозрачными и контрастными.

UIKit/iOS определяет содержимое и границы подложки окна расширения: нельзя обещать точную прозрачность нативной клавиатуры в каждом приложении. При включённом «Понижении прозрачности» используется сплошная системная подложка; изменение отслеживается без перезапуска.

## Установка обновления

Загрузить содержимое архива обновления в корень существующего репозитория, сохранив папки `App`, `Core`, `Keyboard`, `Shared` и `Docs`. Запустить новую GitHub Actions сборку. IPA установить поверх предыдущей через SideStore, сохранив расширение. Проект и workflow менять не требуется; новые исходники и тесты пакета SPM обнаруживает автоматически.

## Проверки

Добавлены шесть XCTest для цифр EN/RU/UK, валютных символов, отключения символов без потери языковых вариантов, uppercase, уникальности вариантов и неизвестных клавиш. Это добавляет тесты к существующим 16.

На устройстве проверить:

1. ⚙ → режимы виброотклика; «Нет» не создаёт генератор. Смена силы даёт пробный импульс, если iOS его разрешает.
2. Сохранение настроек после скрытия и повторного открытия клавиатуры, в том числе без Full Access.
3. Быстрый tap печатает букву ровно один раз; удержание печатает цифру/символ без дополнительной основной буквы.
4. `е → 5/ё`, `г → 7/ґ`; выбор вариантов слева/справа и у краёв экрана; отмена при скрытии и повороте.
5. Выключение символов и меток независимо, задержки удержания.
6. Фон в Notes/Telegram/Safari, светлая и тёмная темы, включение/выключение Reduce Transparency; отсутствие просвечивания сквозь сами клавиши.
7. Доступность ⚙ и дополнительных действий VoiceOver, прокрутка настроек в landscape.

Статус: структурная проверка выполнена в Linux. Новые XCTest и новая Xcode-сборка здесь не запускались — Swift/Xcode отсутствуют. Прежняя версия собрана пользователем в GitHub Actions; это не проверка данного обновления.
