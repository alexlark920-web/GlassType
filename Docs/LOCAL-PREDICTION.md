# Локальное предсказание текста

GlassType использует лёгкий статистический предиктор из `KeyboardCore`, работающий внутри расширения клавиатуры. Это не Core ML и не нейросеть: в репозитории нет `.mlmodel`, весов модели или отдельного скачиваемого model bundle. Решение выбрано как локальный резервный вариант из исходного технического задания, потому что готовой трилингвальной модели с проверенной лицензией и измеренными затратами памяти/latency в проекте не было. Новая сторонняя модель или корпус без оценки лицензии не добавлялись.

## Компоненты

- `CandidateGenerator` ограничивает предложения словами из встроенного частотного словаря и явного личного словаря. Учитываются язык, префикс и настройка фильтра ненормативных слов.
- `PredictionEngine` ранжирует текущие варианты по частотности и статистике личного профиля. Если в контексте ещё не встречался переход, порядок слов остаётся словарным. Следующее слово предлагается только после того, как локально накоплен переход для соответствующего контекста.
- `AutocorrectionEngine` использует ту же персональную статистику отдельно от геометрической вероятности клавиш, частотности слов и стоимости опечатки. Автозамена по-прежнему происходит только при разрешённом разделителе и может быть отменена.
- `PersonalNGramModel` хранит агрегированные счётчики для контекстов из одного и двух предшествующих слов. Контекстные слова преобразуются в SHA-256 ключи, разделённые по EN/RU/UK; для следующего слова сохраняется ограниченный счётчик, не последовательность сообщения.
- `LocalPredictionModelStore` сериализует профиль в `UserDefaults.standard` sandbox клавиатурного расширения. App Group и Full Access для его чтения или записи не используются.

## Персонализация и приватность

Обучение включено по умолчанию и имеет отдельный переключатель. Оно происходит после подтверждённого завершения слова разделителем, свайпом, подсказкой или автозаменой. Слова из secure-полей, неподходящих структурированных полей и запрещённая настройкой ненормативная лексика не обучаются. Данные разделены по языку. Пользователь может отключить обучение и удалить профиль кнопкой сброса в настройках клавиатуры.

Профиль не содержит текста сообщений, истории последовательности ввода, выбранных координат, временных меток или паролей. Чтобы персонализация могла вернуть выученное следующее слово, в ограниченном профиле остаются само слово-кандидат и его небольшой счётчик в контексте хешей. Это локальные языковые агрегаты, а не обезличивание с криптографической защитой: использовать реальные приватные сообщения в качестве тестовых данных не следует. Для чувствительных полей обучение и персонализированная автозамена отключаются.

Границы модели: не более 128 контекстов, 8 слов на контекст и 1 000 наблюдений для одного перехода; сериализованный профиль ограничен 48 KiB. Если новый профиль превысит лимит, запись пропускается. Встроенные частотные словари остаются отдельными ресурсами с атрибуцией и лицензиями в `Core/Sources/KeyboardCore/Resources/Dictionary-Attribution.txt`.

## Производительность и дальнейшая замена

Модель держит только малый агрегированный профиль и ранжирует ограниченный набор кандидатов; вычисления подсказок идут в фоновой очереди, ввод не ожидает результат и устаревшие запросы отменяются. В этой среде нет macOS/Xcode и физического устройства, поэтому время загрузки, latency, память и влияние на батарею не измерены. Цель до 50 ms из технического задания остаётся целью измерения, а не заявленной характеристикой.

Для интеграции Core ML сначала нужны: модель с подтверждёнными лицензиями EN/RU/UK, описание набора обучения, размер сжатых весов, результаты Core ML Performance Reports на поддерживаемых устройствах, пиковая память расширения и regression-набор против текущих словарных тестов. Новую модель можно подключить как отдельную реализацию ранжировщика за `PredictionEngine`, сохранив генератор кандидатов, локальное хранение, privacy guards и fallback без модели.
