# Бинарные словари KeyboardCore

`Scripts/build_binary_trie.py` компилирует `lexicon_{en,ru,uk}.txt` в одноимённые `.trie` ресурсы. Скрипт принимает слова по одному на строке и строки `слово<TAB>частота`; при наличии частоты порядок исходных строк сохраняет ранжирование. Без частоты используется порядок строк файла. Команда `python3 Scripts/build_binary_trie.py --check` проверяет, что бинарные ресурсы совпадают с исходными списками.

## Формат

Файл состоит из шестибайтных узлов. Первые шесть байт — sentinel root. Далее каждая запись имеет вид:

| Смещение | Поле |
| ---: | --- |
| 0 | Один байт UTF-8 пути |
| 1 | `0x01` — терминальный узел, `0x02` — следующий узел того же уровня следует через 6 байт |
| 2–5 | Абсолютное смещение первого дочернего узла от начала файла, `UInt32 little-endian`; `0` означает отсутствие детей |

Узел соответствует **байту**, а не Unicode scalar: кириллические буквы занимают несколько узлов UTF-8. Соседние узлы одного уровня расположены подряд и отсортированы по байту. Узлы детей размещаются после всей группы соседей. Смещения кратны шести.

## Использование и память

`MappedBinaryLexicon` удерживает `Data(contentsOf:options:.mappedIfSafe)` и выполняет точный поиск непосредственно по переданному буферу UTF-8. API `contains(_ utf8Bytes:)` не создаёт строк и не строит индекс. Prefix API создаёт строки только для возвращаемых результатов. Экземпляр immutable и помечен `@unchecked Sendable`; backing `Data` удерживается на весь срок использования отображённых байтов.

`OfflineLexicon` хранит отображение только выбранного языка. Для сохранения частотного порядка ранги небольшого списка кандидатов считываются сканированием memory-mapped текстового файла; большой таблицы `[String: Int]` нет. При смене языка кеш предыдущего словаря сбрасывается. В полёте начатая операция может удерживать старое отображение до своего завершения.

Геометрический индекс `GlideDecoder` строится только при первом свайпе и отдельно хранит кандидаты/траектории. Его временная память, UIKit, память процесса и файловый кэш ОС не контролируются mmap trie; поэтому лимит RSS `< 5 MB` нельзя гарантировать только размером `.trie`. Проверяйте RSS на устройстве отдельно с обычным вводом и во время свайпа. Тестовые временные пороги зависят от runner и не заменяют Instruments.
